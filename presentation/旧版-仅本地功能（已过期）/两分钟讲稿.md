## 使用规则

- 讲稿是草稿，不要照着页面逐字读。
- 第 5、6 页含【待补】句：真实日期和真实分工补齐之前不得照读，补齐后再计时试讲。
- 第 5 页的甘特图目前只是“阶段回顾示意”，没有真实日期；正式汇报前必须按真实起止日期重绘。
- 第 3 页的 Git 现状取自 2026-11-06 的核对：16 次提交、均出自同一作者，按功能分阶段提交；`codex/local-backup`、`codex/local-fifo-fixes`、`codex/symlink-metadata` 均已合并到 `main`，并推送到 GitHub 远程 `origin`；没有配置 CI。提交时间只集中在 2026-11-02 与 2026-11-05 两天，是整理后的提交，**不能**当作多人协作或真实工期的证据。之后若再有提交或分支变动，请重新核对。
- 第 2 页说“常规功能使用 JDK 标准库”，因为 FIFO 恢复另调系统的 mkfifo / touch；不要说成“完全没有外部依赖”。FIFO 只在 POSIX 环境可用，设备文件和 socket 仍不支持。
- 第 4 页的 87 个用例（macOS）与界面冒烟验证分开表述；界面冒烟验证最近一次记录早于属主 / FIFO / 软链接属性的修改，演示前请用当前 JAR 重新走一遍。软件变更后重新测试，数字以最新 surefire 报告为准。
